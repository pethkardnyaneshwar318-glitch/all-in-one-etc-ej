# All-in-One E&TC EJ — fixed starter website

## Publish on GitHub Pages
1. Open your repository: `all-in-one-etc-ej`.
2. Open `index.html`.
3. Tap the pencil/Edit button.
4. Select all existing code and replace it with the contents of this new `index.html`.
5. Commit changes to the `main` branch.
6. Wait a minute or two, then refresh your GitHub Pages website.

Alternatively, download the ZIP, extract it, and upload/replace `index.html` in the repository.

## Important
- This is a responsive starter site with a working English/Marathi selector, semester buttons, search, study sections, and local progress checkbox.
- Some semester subject lists are starter examples. Verify them against the latest MSBTE syllabus.
- Only a small sample of Mobile & Wireless Communication notes and questions is included; the full notes/PYQ database is not included yet.
- The progress checkbox is saved only in the same browser/device using localStorage.

Micro Projects

Project 1: Automatic Room Light using LDR

Aim: Switch an LED on in low light and off in bright light using an LDR sensor and low-voltage circuit.

Components: LDR, resistor, transistor or Arduino-compatible board, LED, breadboard and jumper wires.

Working: LDR resistance changes with light intensity. The circuit compares the sensor level with a threshold and switches the LED.

Applications: Night-lamp and energy-saving demonstrations.

Safety: Use low-voltage DC only. Never connect a breadboard directly to mains electricity.

Project 2: Temperature Monitor using Arduino

Aim: Read room temperature from a compatible sensor and display it on the Serial Monitor.

Components: Arduino-compatible board, temperature sensor, USB cable and jumper wires.

Procedure: Connect the sensor according to its datasheet, upload a read-and-display program, compare readings under different room conditions and record observations.

Result: Temperature readings can be displayed and recorded.

Project 3: Water-Level Indicator (low-voltage demo)

Aim: Indicate low, medium and high water levels using sensor probes and LEDs.

Components: Low-voltage supply, LEDs, resistors, sensor wires and transistor stages or a microcontroller.

Working: Water touching each probe changes the input state and turns on the matching indicator.

Safety: Keep the prototype low-voltage; do not use it for drinking-water safety or mains-powered pump control.

Project report format

  1. Title page and student details
  2. Aim and objectives
  3. Block diagram and components list
  4. Working principle
  5. Procedure / algorithm
  6. Observations and result
  7. Applications, limitations and future scope
  8. References

Quick Unit Test — Mobile & Wireless Communication

  1. What is a cell in a cellular network?
  2. Expand GSM and CDMA.
  3. What is frequency reuse?
  4. Why is handoff required?
  5. Write two differences between 4G and 5G.
Show sample answers
  1. A geographical coverage area served by a base station.
  2. Global System for Mobile Communications; Code Division Multiple Access.
  3. Reusing the same frequency channels in cells separated enough to reduce interference.
  4. To maintain an active call/data session as a user moves between cells.
  5. Possible points include capacity, latency and use cases; verify with the current syllabus.

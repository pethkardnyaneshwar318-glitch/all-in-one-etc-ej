# All IN ONE E&TC (EJ) — Website Starter

## Included
- Mobile-friendly responsive homepage
- K-Scheme starter subject list for Semesters 1–6
- Scheme selector (J-Scheme and other scheme are placeholders)
- Search and section navigation
- Placeholder sections for Notes, Unit Tests, PYQ, Manual/Model Answers, Projects, Jobs, Downloads and Progress
- Local browser progress demo

## Preview
Open `index.html` in a web browser.

## Important
This is a starter prototype, not a fully populated study portal and not yet published online. Login, cloud sync, admin panel, notifications, ads, and real downloadable PDFs are not connected yet. Verify semester/subject codes against the latest official MSBTE syllabus before relying on them.

## Publish for free
This static website can be hosted using a free static hosting service such as GitHub Pages. You will need to create/sign in to your own account and upload the website files; a free hosted link is not created automatically by this ZIP.
